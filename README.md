# Home Decor

A website project with a plain HTML, CSS, and JavaScript frontend and a placeholder backend structure.

## Project structure

- `frontend/` contains the website files.
- `backend/` contains empty folders ready for backend code.

## Run locally

Open `frontend/index.html` in a browser, or use the VS Code Live Server extension.

## Push to a new GitHub repository

Create an empty repository on GitHub, then run these commands from this project folder. Replace the URL with your repository's URL.

```sh
git init
git add .
git commit -m "Initial project structure"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```
